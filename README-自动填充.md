# 第一单元填充试运行

答案源：`读写提高级U校园答案/U1读写 提高.docx`，使用 ZIP + XML 结构化解析，未修改原文件。子目录包含 U1–U6 原始答案文档，脚本仅处理 U1。

当前适配：Unit 1 Challenge / Academic exploration 1 的 Words in use（8 空）和 Translation（4 题）。不是整个第一单元的一键完成脚本；其他练习、已提交练习、拖拽和富文本编辑器会拒绝处理。Safari 实地确认了这两页的路径、题干和字段数量，但浏览器控制台脚本的真实 DOM 兼容性仍需现场验证。

验证记录：2026-09-16，直接操作已登录 Safari，在 Words in use 填入并核对全部 8 个词，在 Translation 填入并核对全部 4 个答案，两页均未点击提交、未进入答案解析。Safari 原生直接赋值出现定位错位，逐框点击并粘贴后已全部校正。该记录验证的是实际网页填充结果，不代表控制台脚本已在 Safari 中执行验证。8 项离线模拟 DOM 测试通过，不替代真实浏览器兼容性测试。

## 使用

在 Safari 已登录的教材标签页，进入上述任一练习。通过 Safari 的网页检查器控制台加载 `unit1-autofill.js` 的内容。需要已有的控制台访问权限，本脚本不修改 Safari 设置，也不安装扩展。

```javascript
UnipusUnit1.preview() // 只检查并显示答案，不填写
await UnipusUnit1.fill() // 只填写当前练习，不翻页、不提交
```

默认加载脚本不改变答案。路径、题干顺序、字段数量或已有草稿不符合预期时拒绝执行。填充后保留当前页，人工核对，不刷新、不翻页，避免未提交答案丢失。

脚本不读取账号、密码、Cookie，不请求网站 API，不播放视频，不修改学习进度，不触发提交或导航。填充使用普通 input/change 事件；网站自身如监听输入自动保存草稿，仍可能保存草稿。提交拦截是额外保护，不是对网站所有内部自动行为的保证。填充后还会拦截页面提交事件、提交文字点击及输入框 Enter；重新载入页面可移除脚本和拦截，但也可能丢失未保存的草稿。

## 重新生成

```sh
python3 build_unit1.py
node --test test-unit1.cjs
```

无需第三方 Python 依赖。生成 `unit1-answers.json` 和独立的 `unit1-autofill.js`。模板是 `unit1-autofill.template.js`。Word 中的播放、滑动等操作说明不作为脚本指令。

测试需要 Node.js 18 或更新版本。仓库不应包含账号、密码、Cookie、浏览器配置或学习记录。答案文档可能涉及教材版权，公开分享前需确认有分发权限；建议先使用私有仓库。不附加未经确认的开源许可证。
